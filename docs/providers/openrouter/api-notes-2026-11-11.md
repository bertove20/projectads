# OpenRouter API — catatan terverifikasi (diperiksa 11 November 2026)

Sumber resmi: https://openrouter.ai/docs/api-reference/chat-completion,
https://openrouter.ai/docs/api-reference/models/get-models,
https://openrouter.ai/docs/guides/features/tool-calling. Periksa ulang sebelum mengubah integrasi.

## Autentikasi
`Authorization: Bearer <OPENROUTER_API_KEY>`, `Content-Type: application/json`. Key hanya dipakai di server.

## GET /api/v1/models
- Wajib Bearer token (tanpa token → 401).
- Respons: `{ data: Model[], total_count, links: { next } }`; `limit` default 500 (maks 1000), `offset`.
- Field yang dipakai EAIP: `id`, `name`, `context_length`, `pricing.prompt`, `pricing.completion`
  (**string, USD per token**), `top_provider.max_completion_tokens`, `supported_parameters` (berisi `tools` bila mendukung tool calling).

## POST /api/v1/chat/completions
- Body: `model`, `messages` (role `system|user|assistant|tool`), `tools` (`{type:"function", function:{name, description, parameters}}`),
  `tool_choice`, `max_completion_tokens` (`max_tokens` deprecated), `temperature` (0–2).
- `tools` wajib disertakan lagi pada request lanjutan yang berisi hasil tool.
- Assistant dengan tool: `message.tool_calls[] = { id, type:"function", function:{ name, arguments: "<JSON string>" } }`.
- Hasil tool: `{ role:"tool", tool_call_id, content: "<string>" }`.
- `usage`: `prompt_tokens`, `completion_tokens`, `total_tokens`, `cost` (USD, bisa null) — selalu disertakan.
- Error: `{ error: { code, message, metadata? } }`; status 400/401/402/403/404/408/413/422/429/5xx.
